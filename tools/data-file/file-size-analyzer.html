What is the File Size Analyzer?

The File Size Analyzer is a client-side disk space auditing utility designed to analyze the storage footprint of your local files. By importing batches of files directly into the browser tab, you can instantly see a running total of the file counts, aggregate sizes, and category percentages.

This analyzer helps identify large files that are consuming storage space. Because all file index readings and statistics calculations occur locally in browser memory, your filenames, file paths, and storage architectures are kept completely private.

How to Use the File Size Analyzer

  1. Upload Your Files: Drag and drop your files into the dotted drop zone, or click inside the zone to select them from your computer.
  2. Observe the Overview Stats: The tool instantly displays the "Total Files" and "Total Size" of all selected files at the top of the interface.
  3. Review the Format Breakdown: Check the generated list or visual breakdown chart. It displays which file categories (such as Images, Documents, Media, or Archives) occupy the largest percentage of your space.
  4. Inspect Individual Sizes: Scroll through the file breakdown table to view filenames, exact byte sizes, and their relative percentage shares in the current batch.

Key Features

  • Instant Storage Tally: Calculates total file count and byte sizes in real time as files are uploaded.
  • Extension Category Mapping: Group files automatically by format types to identify if media, code, or documents consume the most space.
  • Interactive Share Lists: Displays exact byte sizes and percentage footprints for each file to pinpoint heavy assets.
  • Safe Index Scanning: Scans file metadata locally without reading or modifying the actual content of the files.
  • Offline Data Isolation: Audits files offline without transmitting paths or sizes to external servers.

Common Use Cases

  • Downloads Folder Cleanups: Audit a cluttered downloads folder to find and delete large zip files, software installers, or logs.
  • Email Attachment Preparation: Check the combined size of multiple files before emailing them to ensure they stay under server attachment limits.
  • SD Card Space Auditing: Review camera imports or music file libraries to see how space is distributed before formatting cards.
  • Project Resource Inspections: Analyze directory build outputs, node packages, or design folder assets to optimize storage.
