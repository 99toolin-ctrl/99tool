What is the Local Backup Tool?

The Local Backup Tool is a client-side utility designed to manage, export, and restore configuration records and app data stored by 99tool.in inside your browser's LocalStorage. This enables you to download all your custom settings, task lists, and notes as a single backup file.

This utility works entirely on your local machine, reading your browser storage cells and compiling them into a structured JSON file. Because it processes all exports and restores locally, your private data and settings are never synchronized with a cloud server or exposed to third parties.

How to Use the Local Backup Tool

  1. Audit Current Settings: Check the "LocalStorage Status" panel on the left. The tool displays the count of data keys found and the estimated memory size occupied by your browser settings.
  2. Create a Backup: Click the "Create Backup File" button. The tool compiles your settings and initiates a local download of a JSON file named with today's date.
  3. Select a File to Restore: To restore settings, drag your previously downloaded backup JSON file into the dashed area on the right, or click the area to select it from your device.
  4. Restore Your Settings: Once the backup file is loaded, click the "Restore Backup" button to import your configuration. The tool will parse the JSON and write the data back to your browser's LocalStorage.

Key Features

  • One-Click JSON Exports: Bundles all local configuration keys and data structures into a single text file.
  • Interactive Size Reporting: Displays the count of data values and byte sizes currently saved in your browser storage.
  • Cross-Browser Portability: Import your JSON backup files across Chrome, Edge, Firefox, or Safari on different devices.
  • Safe Data Merging: Updates keys during restoration without corrupting or deleting unrelated browser storage keys.
  • 100% Offline Portability: Performs backups and restorations entirely in browser memory to guarantee data privacy.

Common Use Cases

  • Device Migrations: Export your Kanban tasks, notepad text, and custom settings from a home computer and import them to a work laptop.
  • Browser Updates: Back up your tool settings before clearing your browser cookies or upgrading your operating system to prevent data loss.
  • Confidential Backups: Store copies of your encrypted notes or passwords on a secure external USB drive.
  • Environment Resetting: Reset your browser environment for a clean start, knowing you have a backup file saved.
