What is the Directory Comparison Tool?

The Directory Comparison Tool is a client-side file auditing utility designed to compare the contents of two folders. By selecting your target directories, the tool scans filenames and file sizes to identify matches, omissions, and size differences across the datasets.

This comparison focuses on metadata audits, resolving disparities between backup drives or source folders without reading or copying actual file content. Because the indexing scripts execute locally in browser RAM, your file lists and data structures remain confidential and are never uploaded to a cloud server.

How to Use the Directory Comparison Tool

  1. Select Directory A: Click the file selector under "Directory A" and choose your first target folder. Your browser will prompt you to confirm read permissions for the folder contents.
  2. Select Directory B: Click the file selector under "Directory B" and choose your second target folder, confirming permissions as prompted.
  3. Run the Comparison: Click the "Compare Directories" button. The comparison engine will catalog the folder structures and compare the file listings.
  4. Analyze the Results Table: Review the results table. It highlights status changes:
    • Match: The file exists in both directories with identical sizes.
    • Only in A / Only in B: The file is missing from one of the directories.
    • Size Mismatch: The file exists in both directories but has different file sizes.

Key Features

  • Recursive Folder Auditing: Scans nested subfolders to verify complex directory structures.
  • Visual Status Indicators: Color-coded badges highlight matches, missing items, or size discrepancies.
  • Size Difference Reporting: Displays exact byte counts for both directories side-by-side to pinpoint changed files.
  • High-Speed Local Scanning: Indexes and compares thousands of files in seconds without network bottlenecks.
  • Offline Security: Operates entirely within your local browser sandbox to protect folder directories from exposure.

Common Use Cases

  • File Copy Verification: Confirm that all photos, videos, or documents copied successfully from an SD card to an external backup drive.
  • Build Artifact Auditing: Compare software build outputs or resource directories to verify code package consistency.
  • Backup Verification: Cross-reference active project folders with older backup archives to find modified files.
  • Website Deployment Checks: Inspect local web asset folders against server exports to identify files that need updating.
