What is the Folder Size Visualizer?

The Folder Size Visualizer is a client-side disk space diagnostic tool that generates an interactive treemap of your directory structure. By uploading a local folder, you can visualize how much space individual files and subfolders occupy, helping you identify heavy directories at a glance.

Rather than using text list directories, this tool represents sizes as proportional colored blocks (treemaps). Because all file scanning and graphics rendering occur locally in browser RAM, your file naming conventions, folder structures, and system details remain completely private.

How to Use the Folder Size Visualizer

  1. Select Your Directory: Click the "Select Folder" button to launch your system's directory picker. Choose the folder you want to analyze and confirm read permissions.
  2. Wait for Local Indexing: The tool scans the directories, calculating file size proportions and mapping extension colors.
  3. Analyze the Treemap: Examine the generated block diagram. The size of each rectangular block represents the file's space footprint, while the colors indicate the file categories shown in the legend.
  4. Inspect File Details: Hover your cursor over any block to display a tooltip showing the file name, directory path, and exact file size.

Key Features

  • Proportional Block Mapping: Renders folder structures as a nested treemap where block area indicates file size.
  • Dynamic Extension Legends: Color-codes blocks automatically by category (e.g., green for media, orange for documents) for easy scans.
  • Hover Information Tooltip: Displays real-time details (filename, path, byte size) on mouse hover.
  • Recursive Folder Traversing: Scans all subfolders inside the selected directory to build a complete size map.
  • Offline Data Isolation: Renders visual treemaps without uploading directory lists or data to external servers.

Common Use Cases

  • Developer Node Module Audits: Scan project directories or node_modules folders to identify heavy code packages.
  • Video and Photo Library Sorts: View which raw footage files or image exports are occupying the most disk space on backup drives.
  • System Cache Decluttering: Map hidden application folders or temporary cache files to clear disk space.
  • Document Directory Overviews: Inspect corporate directories to check if archived spreadsheets or PDFs need to be compressed.
