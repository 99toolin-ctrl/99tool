Personal Productivity Dashboard

Your modular command center. Configure widgets for tasks, notes, and local tools in one private place.

What is the Personal Productivity Dashboard?

The Personal Productivity Dashboard is a modular workspace that lets you add, arrange, and configure widgets — including notes, task lists, and a live clock — all on a single screen. Standard dashboard tools require a cloud account and sync your workspace layout to remote servers. This tool stores your widget configuration and content exclusively in your browser's localStorage.

Click "Save Layout" to persist your current setup. When you return, your widgets and their content are restored exactly as you left them, with no login required and no data ever leaving your device.

How to Use the Personal Productivity Dashboard

Building your workspace involves these steps:

  1. Use the "Add Widget" buttons in the toolbar to add a Clock, Notes Pad, or Task List widget to your dashboard.
  2. Drag and drop widgets to rearrange them on the canvas to match your preferred layout.
  3. Click inside a Notes widget to start typing directly. Content saves automatically to localStorage.
  4. Add tasks in a Task List widget by typing in the input field and pressing Enter. Check off completed items.
  5. Click "Save Layout" to commit your widget arrangement to localStorage so it persists on reload.
  6. Click the ✕ button on any widget to remove it from the dashboard.

Key Features

  • Modular Widget System: Add any combination of Clock, Notes, and Task List widgets to a single, unified screen.
  • Drag-and-Drop Layout: Rearrange widgets by dragging to build a layout that matches your mental workflow.
  • Persistent Workspace: "Save Layout" commits your full configuration to localStorage, surviving page refreshes and browser restarts.
  • Zero-Account Setup: No login, no cloud sync, and no data transmission — your dashboard is exclusively yours.

Common Use Cases

This dashboard is helpful for the following tasks:

  • Morning Startup Routine: Opening one tab to see your clock, today's tasks, and a scratchpad for notes instead of switching between multiple apps.
  • Freelance Project Hub: Keeping active project notes and daily task lists side-by-side in a private, account-free workspace.
  • Study Dashboard: Arranging a notes widget for key concepts alongside a task list for study targets and a clock for timed sessions.

Frequently Asked Questions

What widgets are available?
The current version supports a Live Clock widget, a free-form Notes Pad, and a basic Task List. More widgets (calendar, Pomodoro timer, habit tracker) are planned for future updates.

Is my dashboard saved automatically?
Widget content (notes, tasks) is auto-saved as you type. The widget layout requires a manual click on "Save Layout" to persist the arrangement.

Can I use this on multiple monitors?
Yes. Open the tool in a separate browser window and arrange it on your second monitor as a persistent command center.

Does clearing browser data erase my dashboard?
Yes. Clearing site data for 99tool.in removes your saved layout and widget content. Export important notes before a browser reset.

Privacy & Data Note

All widget content, layout configuration, and task data are stored entirely inside your browser's localStorage. No dashboard data is transmitted to any server or third-party service.
