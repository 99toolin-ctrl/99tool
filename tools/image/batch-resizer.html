What is the Batch Image Resizer?

The Batch Image Resizer is a client-side image processing utility designed to scale multiple images simultaneously. By setting target dimensions or percentage scales, users can resize batches of photos, screenshots, and designs locally in their browser.

This utility processes all image loading, aspect ratio scaling, canvas redraw operations, and ZIP bundling locally in your browser memory. Your original graphics, photos, and resized files are never uploaded to any server, ensuring complete confidentiality.

How to Use the Batch Image Resizer

  1. Select Your Images: Drag and drop multiple image files into the dotted drop zone, or click to browse and select them.
  2. Choose Resize Mode: Select "Target Width", "Target Height", or "Percentage Scale" from the dropdown menu.
  3. Define Value: Input the target pixel dimension or scale percentage in the value field (e.g., 800 for width, or 50 for half size).
  4. Set Output Format: Choose your preferred file format (JPEG, PNG, or WebP) from the format selector.
  5. Process and Save: Click the "Process & Zip" button. Once background queue rendering completes, the ZIP archive downloads automatically.

Key Features

  • Flexible Resizing Modes: Scale by target width or height (retaining proportions) or by percentage.
  • Interactive Queue Manager: View a list of selected files and processing status in a dedicated queue panel.
  • Output Format Control: Convert output formats dynamically to JPEG, PNG, or WebP during resizing.
  • Bilinear Canvas Rescaling: Employs high-quality canvas drawing logic to minimize pixelation and blur.
  • ZIP Export Bundling: Automatically packages all scaled outputs into a single structured ZIP file using JSZip.

Common Use Cases

  • Site Asset Optimizations: Bulk resize raw website assets to specific container widths for faster page load times.
  • Camera Exports Compression: Shrink large megapixel camera photos to manageable sizes before sharing with clients.
  • Document Preparation: Resize screenshots and product photos uniformly before inserting them into company PDFs or docs.
  • E-commerce Product Catalogs: Format product images to standard dimensions for online store listings.
